# quanttide-org
量潮组织管理

## 概述

量潮组织管理（quanttide-org）是量潮知识管理体系中的**组织管理**领域，涵盖组织架构设计、行政管理、组织发展与文化建设等核心能力。

## 领域边界

- **企业治理**：治理架构设计（创始人—上议院—下议院三权并列）、权力让渡与演进、议事制度设计意图
- **组织架构**：部门设置、岗位体系、权责划分
- **行政管理**：日常行政事务、资产管理、办公流程
- **组织发展**：人才发展、绩效管理、文化建设
- **制度规范**：管理制度、流程标准、合规运营

> 与 delib 领域的分工：本领域承载"谁有权、怎么管"（企业治理实际情况），delib 承载"议题怎么走流程"（议事规则）。
